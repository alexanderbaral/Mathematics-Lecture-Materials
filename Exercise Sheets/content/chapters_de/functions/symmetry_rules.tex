\begin{ExerciseBlock}
\ExerciseHeading{3}{Symmetrieregeln}{functions_symmetry_rules}
Errechnen Sie die Symmetrie-Eigenschaft (d.h. gerade oder ungerade Symmetrie) ... 
\begin{enumerate}[label=\alph*)]
\item der Summe zweier gerader Funktionen.
\item des Kehrwerts einer ungeraden Funktion.
\item des Quadrates einer ungeraden Funktion.
\item der Summe einer geraden und einer ungeraden Funktion.
\item der Komposition zweier ungerader Funktionen, d.h.$g_\text{u}\left( h_\text{u}\left( x \right) \right)$.
\end{enumerate}
... und nennen Sie jeweils ein Beispiel.

\end{ExerciseBlock}
