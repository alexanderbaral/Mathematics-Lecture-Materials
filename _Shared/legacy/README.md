# Gemeinsames Archiv

Altmaterial kann hier abgelegt werden. Die Unterordner Skript und Exercise Sheets enthalten die bisher getrennten Archive; ihre Dateien wurden unverändert verschoben.

Dieser Bereich gehört nicht zu den aktiven Lehrinhalten und wird weder für die Bauauswahl noch für Änderungsüberwachung oder Quellsnapshots durchsucht. Neues Altmaterial löst keinen PDF-Bau aus.

Neue Archivdateien werden von Git standardmäßig ignoriert. Die zwei bereits versionierten Referenzdateien bleiben versioniert; die bisher nicht versionierten Skript-Altdokumente bleiben lokal.
