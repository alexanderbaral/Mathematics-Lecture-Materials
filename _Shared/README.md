# Gemeinsamer Bereich

- style: gemeinsame Stildefinitionen.
- commands: gemeinsame mathematische, Sprach- und Codebefehle.
- resources: gemeinsam verwendete Grafiken, Symbole und Schriften.
- tools: aktive gemeinsame Bausteuerung, Cache-Prüfung und Tests.
- legacy: gemeinsame Ablage für Altmaterial aus beiden Dokumenttypen und neue Archivdateien.

Die Bausteuerung verwendet tools bereits. Die LaTeX-Stildateien liegen bis zu ihrer gezielten Auslagerung weiterhin in den common-Verzeichnissen der Produkte. Aktive gemeinsame Ressourcen werden bei beiden Bauten berücksichtigt. legacy wird von Snapshot und Änderungsüberwachung vollständig ausgenommen.
