# Gemeinsamer Bereich

Vorbereitete Zielstruktur für gemeinsam verwendete Bausteine beider Dokumenttypen:

- style: Schrift-, Farb- und grundlegende Boxdefinitionen.
- commands: Sprachumschaltung, Gleichungsdarstellungen und Codebefehle.
- resources: Schriften, Logos, Smileys und sonstige wiederverwendbare Abbildungen.

Dieser Ordner ist bisher vorbereitet, aber noch nicht in die LaTeX-Bauten eingebunden.
Bei der Auslagerung müssen auch die Abhängigkeiten der Bauwerkzeuge angepasst werden,
damit Änderungen an gemeinsamen Dateien beide Dokumenttypen zuverlässig aktualisieren.
