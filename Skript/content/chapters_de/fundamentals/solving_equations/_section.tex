\section{Lösen von Gleichungen}
\label{sec:fundamentals_solving_equations}

Das sichere Umstellen von Gleichungen ist eine der wichtigsten Fähigkeiten
eines Ingenieur und damit eine absolut zentrale Grundlage der
Ingenieurwissenschaften: Es ermöglicht, technische Zusammenhänge nach der
jeweils gesuchten Größe aufzulösen.

Beim Umformen einer Gleichung wird auf beiden Seiten dieselbe zulässige
Rechenoperation durchgeführt. Dadurch entsteht eine äquivalente Gleichung mit
derselben Lösungsmenge. Dies kann man fortsetzen, bis die gesuchte Variable isoliert ist.

Zur Erläuterung wird die jeweils ausgeführte Rechenoperation zunächst rechts
neben der Gleichung notiert; im weiteren Verlauf der Vorlesung wird diese
Angabe nicht immer explizit ergänzt.
