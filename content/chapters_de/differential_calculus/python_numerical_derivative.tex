Um numerisch abzuleiten, verwendet man häufig den folgenden Differenzenquotienten.
\begin{equation*}
	f'(x) \approx \frac{ f(x + \epsilon) - f(x - \epsilon) }{2 \epsilon}
\end{equation*}

wobei $\epsilon$ eine kleine positive Zahl ist, z.B. $\epsilon = 10^{-6}$. Zu kleine Werte können Rundungsfehler verstärken.

\begin{enumerate}[label=\alph*)]

\item Verwenden Sie den Code um sich den Verlauf der Ableitung einer beliebigen Funktion sowie die dazugehörige Funktion ausgeben zu lassen.

\item Untersuchen Sie die Ableitungen von Funktionen mit gerader und ungerader Symmetrie. Welche Symmetrien weisen jeweils die Ableitungen dieser Funktionen auf?

\end{enumerate}
